# 🎮 NEXUS: LIFE BEYOND CODE

A full-fledged, real-life college student simulation game built with **React**, **Vite**, **Recharts**, **Lucide Icons**, and **Web Audio API**.

## 🚀 Quick Start
```bash
npm install
npm run dev
```
Navigate to `http://localhost:5173/`.

For full walkthrough and professor presentation guidelines, see [NEXUS_GUIDE.md](../NEXUS_GUIDE.md).
